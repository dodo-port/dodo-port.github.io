같은 화점에, 같은 번호를 유지하도록

아래 영상의 왼쪽은 ByteTrack 기본 설정, 오른쪽은 제가 연구한 제안 방법입니다. 같은 녹지 영상을 입력해 화점에 붙는 번호가 어떻게 달라지는지 비교했습니다.

왼쪽 · 기준 방식ByteTrack 기본 설정같은 화점에도 새 ID가 생성되는 모습
오른쪽 · 연구 성과연구 성과같은 화점의 번호를 이어가는 추적
왼쪽 기준 · 오른쪽 연구 성과

관찰 포인트: 후반부에서 왼쪽은 새 번호가 붙는 반면, 오른쪽은 기존 번호를 이어갑니다. 상단의 ‘생성 ID’는 지금 보이는 화점 수가 아니라, 영상 시작부터 생성된 ID의 누적 개수입니다.

화점 4곳에서 생성 ID 16개 → 4개

4곳녹지 영상의 화점
16 → 4전체 영상의 생성 ID 수
75%감소이 영상에서 생성된 ID 수

불을 찾아내는 것에 더해, 시간에 따라 같은 불을 같은 대상으로 이어서 추적하는 것이 연구의 목표입니다. 이 녹지 영상에서는 제안 방법의 전체 생성 ID 수가 화점 수와 같은 4개로 줄었습니다.

어떤 연구를 통해 달라졌나요?

01 / 문제

하나의 불이 여러 상자로 나뉩니다

불꽃과 연기는 모양이 계속 달라져 한 화점에서 여러 검출 상자가 생기거나 신뢰도가 낮아집니다. 기존 추적 기준에서는 같은 화점의 연결이 끊기고 새 번호가 붙을 수 있습니다.

02 / 제안

화점의 연속성을 고려했습니다

프레임마다 달라지는 관측 결과를 같은 화점으로 이어갈 수 있도록 추적 과정을 개선했습니다. 비교 영상에서 번호가 유지되는 모습을 확인할 수 있습니다.

03 / 의미

화점별 관찰을 이어갈 수 있습니다

번호가 유지되면 같은 화점의 위치와 변화를 시간에 따라 연결해 볼 수 있습니다. 화점별 대응을 위한 추적 기반을 다루는 연구이며, 실제 진화 효과를 검증한 결과는 아닙니다.

결과 범위: 최종 발표자료의 녹지 영상 비교. 75%는 (16−4)/16으로 계산한 생성 ID 수 감소율이며, 추적 정확도 향상률이 아닙니다. 해당 영상의 결과이며 다른 촬영 조건에서의 성능을 보장하지 않습니다.
