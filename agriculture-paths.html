정밀농업 UAV 탐색 경로

같은 환경, 달라지는 탐색 경로

왼쪽은 기준 방식, 오른쪽은 CBAM과 다중 스케일 구조를 적용한 방식입니다. 동일 지도·시작점·설정에서 평가한 경로와 탐지 기록을 같은 스텝 기준으로 재생합니다. 한쪽의 기록이 먼저 끝나면 마지막 위치에 머뭅니다.

Step 0

회색은 미탐지 잡초, 검은색은 탐지된 잡초, 큰 원은 UAV 위치입니다.

30개 비교 평가 중 두 방식 모두 높은 탐지율을 보이면서 차이가 나는 시뮬레이션 사례를 선정했습니다. 색 변화와 탐지율은 실제 기록을 따릅니다. 선정 사례가 전체 평균을 뜻하지는 않습니다.

전체 비교 결과 · 선정 기준

30개 사례의 최종 탐지율 비교: 연구 방식 우세 15개, 동률 1개, 기준 방식 우세 14개. 사례별 평균 탐지율은 기준 방식 66.2%, 연구 방식 74.8%입니다. 최종 탐지율은 실제 잡초 중 찾아낸 비율이며 오탐은 제외합니다.

완전 탐지 사례: 기준 방식 0개, 연구 방식 0개. 두 방식 모두 80% 이상 탐지한 사례에서, 차이가 뚜렷한 경우와 작은 경우를 각각 골랐습니다. 새로 실행한 시뮬레이션 결과이며 논문 전체 평가의 재현 결과는 아닙니다.
